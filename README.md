# Personal Portfolio Website 🚀

Welcome to my personal portfolio website! This project is a responsive, front-end web application designed to showcase my academic background, technical skill set, and hands-on coding experience in a clean, professional layout. 

## ✨ Features
* **Dynamic Theme Toggle:** Smoothly switch between **☀️ Light Mode** and **🌙 Dark Mode** with user preferences saved instantly via `localStorage`.
* **Fluid Animations:** Includes a continuous animated headline banner and modern scroll-triggered skills progress bars using the `IntersectionObserver` API.
* **Fully Responsive Layout:** Optimized using CSS Media Queries to look professional and legible on smartphones, tablets, and desktop displays.
* **Smooth Navigation:** Clean, frictionless intra-page smooth scrolling for enhanced user experience.
* **Functional Front-End Form:** Built-in form validation and automated client-side success messaging feedback loop.

---

## 🛠️ Built With
* **HTML5:** Semantic document structure for enhanced accessibility and SEO.
* **CSS3 (Custom Variables):** Dynamic styling architecture featuring central color variables for seamless dark-mode themes.
* **Vanilla JavaScript:** Clean, asynchronous DOM manipulation and event-driven animations without relying on heavy external libraries.
* **Google Fonts:** Typography powered by the modern and readable *Poppins* font family.
